# 03 · 业务生命周期（UI 主闭环）

> 只描述「用户从入口走到业务完成、结果被下游消费」的生命周期；不改变 `docs/03` 定义的状态机语义。三元组 `(前置状态, 操作, 后置状态)` 见 `13-state-machines.md`。

## 1. 主业务生命周期（数据工作区，一级主流程）

```
未连接
  └─(选择/新建连接 + 令牌就绪)→ 已连接（state.current 就绪，环境/身份/能力位加载）
       └─(浏览/搜索对象树)→ 已选定对象（表）
            └─(写 SQL / 点表浏览)→ 编辑器就绪（SQLTab.sql 或 loadTablePage）
                 └─(执行 runSQL)→ 执行中（计时器、可取消、慢查询报时、风险/摩擦徽标）
                      ├─(成功)→ 有结果（result-block 网格 / 可编辑表 + pending-bar）
                      ├─(失败)→ 失败块（第 N 条 · 失败：err）→ 可重试 / 回编辑器改语句
                      └─(取消)→ 已取消（引擎侧语句终止）→ 回到编辑器就绪
                           └─(改数据：单元格/插删行)→ 待提交变更集（pending，dirty 标记）
                                ├─(提交)→ 预案预览（前后对比 + 影响 + 回滚 SQL + R3/R4 二次确认）
                                │    ├─(批准 apply)→ 已提交（结果被 service 持久化）→ 可一键撤销
                                │    └─(拒绝/冲突)→ 回到待提交（内容不丢，乐观并发冲突提示）
                                └─(丢弃)→ 回到有结果（变更集清空）
```

## 2. 次要域生命周期（按任务进入，返回不丢上下文）

- **结构设计**：进入「结构」域 → 选对象/新建 → 填表 → DDL 预览 → `plan` → 影响/回滚展示（不可逆用 `danger` 红，`irreversible_style_test.go`）→ `apply` → 结构刷新 → 回到结构域/数据域（当前连接不变）。
- **结构比对**：进入「结构」域 → 选两侧连接 → `runCompare` → 差异清单（物化视图单独标注，`compare_ui_test.go`）→ 升级/回退脚本 → 只读结束。
- **监控**：进入「监控」域 → 选面板（指标/会话/体检）→ 首屏结论（`docs/09` §3.1）→ 面板关闭即停采集（MutationObserver，`metrics_ui_test.go`）→ 返回。
- **AI Agent**：进入「AI」域 → 会话（按连接隔离）→ 步骤时间线 → 待批预案（`approvalCard` 展示最终 SQL）→ 批准/拒绝 → 结论附证据 → 可导出会话。
- **运维任务（界面未接入）**：`docs/12` §2.6 标注长任务形态（tasks 表/进度/暂停续跑）未实现；当前仅 CLI/API 同步端点。重设计保留分组入口位，标注「CLI/API 可用、界面未接入」，不进入主生命周期。

## 3. 前置/后置条件（关键操作）

| 操作 | 前置 | 后置 | 数据变化 | 幂等 |
|---|---|---|---|---|
| selectConnection | 令牌就绪、连接存在 | `state.current`、能力位、对象树刷新 | 前端 state + 后端会话 | 是 |
| runSQL | 已连接、编辑器有 SQL | result-block / 失败块 | 只读不改库；写走执行门 | 否（写） |
| submitChanges | 有 `pending` 且非只读 | 预案 → 已提交/冲突 | 库内行变更 + 审计 + 回滚预案 | 冲突整体回滚 |
| planSchemaAction | 已连接、动作受 capabilities 支持 | ChangePlan(pid) 服务端保管 | 不直接改库 | 是 |
| applyPlan | plan 指纹匹配、审批通过 | 结构/数据变更落库 | DDL/DML + 审计 | 绑定指纹 |
| killSession | `caps.kill_session` 且非只读且已确认 | 会话终止（不可逆） | 引擎侧 + 审计 | 否 |
| switchDomain | 已连接 | 激活域切换，`state.current` 不变 | 无业务数据变化 | 是 |
| openSettings/saveSettings | 令牌就绪 | 主题/字号/模型配置生效 | 设置文件 + Key 进凭据库 | 是 |
